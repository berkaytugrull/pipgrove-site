利用規約

Pipgroveは添加糖を減らすための習慣づくりのコーチアプリです。ご利用にあたり、個人的かつ非商用の目的で使用することに同意したものとみなします。

Pipgrove Pro は Apple ID を通じて請求される自動更新のサブスクリプションです。価格と請求期間は購入前に表示されます。無料体験が提供される場合、終了の24時間前までに解約しない限り有料のサブスクリプションに移行します。管理や解約は Apple ID の設定からいつでも行えます。

Apple の標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。

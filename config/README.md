Remote settings read by the Pipgrove iOS app (1.1.0+) on each launch: src/native/remote.ts.
Unknown keys are ignored; bad values fall back to the app's defaults. Optional keys:
- "headline": English paywall headline, "{cubes}" = the person's 28-day sugar cubes (under 90 chars).
- "notice": {"id","title","body","url"} one-off card on Home, shown once per id.
